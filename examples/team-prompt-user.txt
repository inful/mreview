- Cache key design — is the key collision-free across tenants?
- Invalidation boundaries — does a write to X correctly evict
  the entries that depended on X?
- TTL semantics — what happens on clock skew between nodes?

DO NOT focus on:

- Naming bikesheds (`cache` vs `kvstore` vs `memstore`)
- Import ordering
- Comment style

feedback before polishing the surface.
